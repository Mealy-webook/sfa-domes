Typography

The 17 text styles of WBK DS3, with the same sizes, line heights, letter spacing and case, set in SFA’s own font, Loew Next. Each style has one size on every screen. Switch the mode at the top: the Typography collection swaps its font and weights, and every text style below follows.

3 · Text styles

What designs and pages pick from. The 17 DS3 styles, with the same names as the Figma text styles. Each one is a weight, size, line height, letter spacing and case taken from the layers above: font:var(--ts-*) or the .ts-* classes in f/fonts.css. Sizes are the same on phones and wide screens.

Demo font: missing characters

The Loew Next files are a personal-use demo with letters and numbers only. The highlighted characters come from the fallback font until the licensed files are in.
